Déployer un LLM interne
à la DSI de La Poste

Stage de 3 mois · Branche Services-Courrier-Colis

Trois mois au sein de la DSI de La Poste (BSCC), pour explorer une question simple en apparence : comment une grande entreprise peut-elle utiliser l'IA générative sans envoyer ses données à des fournisseurs externes ?

Le problème

Les outils d'IA grand public (ChatGPT, Copilot) posent un problème de souveraineté des données pour une entreprise comme La Poste, et leur coût à l'échelle devient vite significatif.

L'enjeu du stage était donc de construire une alternative interne, maîtrisée de bout en bout.

Ce que j'ai construit

J'ai déployé un modèle Gemma en interne via vLLM, exposé sous forme d'API. Autour de ce modèle, j'ai développé une interface web type Copilot permettant aux équipes non techniques de l'utiliser au quotidien.

Pour étendre l'usage du modèle au-delà de l'interface web, j'ai également créé un custom node n8n en TypeScript, permettant d'intégrer le LLM interne directement dans des workflows d'automatisation.

Modèle & API

Déploiement d'un modèle Gemma en interne via vLLM, exposé sous forme d'API consommable par les autres outils du système d'information.

Interface type Copilot

Interface web pensée pour les équipes non techniques, d'abord prototypée en Lit/JavaScript puis portée sous Angular en cours de projet.

Anonymisation & accès

Fonction d'anonymisation des documents avant traitement, et authentification OIDC du groupe pour la gestion des accès.

Custom node n8n

Node n8n développé en TypeScript pour brancher le LLM interne directement dans les workflows d'automatisation existants.

Stack et mise en production

L'ensemble a été livré via des pipelines GitLab CI/CD, conteneurisé sous Docker et déployé sur OpenShift, avec la qualité de code suivie sous SonarQube.

Application

Angular TypeScript Lit Python

IA & automatisation

Gemma vLLM n8n OIDC

Livraison

GitLab CI/CD Docker OpenShift SonarQube

Résultat

Les outils développés pendant ce stage sont aujourd'hui utilisés en interne par les équipes de la DSI — une brique pensée pour garder les données dans l'entreprise et réduire les coûts face aux solutions du marché.
