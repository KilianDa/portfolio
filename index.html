V2C Shop

2024

FREELANCE / E-COMMERCE

Réalisation d'un site e-commerce complet pour V2C, une petite marque indépendante de vente de t-shirts. Boutique moderne, esthétique et optimisée pour la conversion.

Projet d'environ 1 mois, véritable challenge car première boutique de cette envergure. J'ai beaucoup appris en développement, relation client et gestion de projet.

Mes missions :

  • Analyse des besoins du client
  • Conception de la maquette et de l'expérience utilisateur
  • Développement Front-end et Back-end de la boutique
  • Intégration d'un système de paiement sécurisé avec Stripe

BottomUp

2025

ACADÉMIQUE / VOTE PARTICIPATIF

Dans le cadre de mon parcours RACDV, nous avons développé un site web de vote participatif. Site en PHP, HTML, CSS et JavaScript développé en équipe de 4 avec méthode agile.

Projet très formateur sur le travail en équipe, l'utilisation d'outils (Trello, Git) et la gestion d'un client (priorités, délais, contraintes).

Mes missions :

  • Mise en place d'une architecture MVC
  • Généralisation du code pour éviter la duplication
  • Conception de la base de données
  • Réalisation des tests unitaires
PHP HTML CSS JavaScript SQL Docker

EatFit

2025

PERSONNEL / APPLICATION MOBILE

Application mobile pour suivre ses données en nutrition et entraînement, réalisée en React Native avec Expo Go sur l'IDE Cursor (IA intégrée).

Suivi des repas, calories, hydratation, programmes et séances d'entraînement, avec base locale SQLite et synchronisation Supabase.

Mes missions :

  • Conception des écrans nutrition (repas, calories, eau)
  • Gestion des programmes et séances d'entraînement
  • Base locale SQLite et synchronisation Supabase
  • Développement avec Cursor AI (React Native, TypeScript)
React Native Expo TypeScript Supabase SQLite
